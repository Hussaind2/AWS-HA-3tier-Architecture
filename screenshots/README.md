# Screenshot Evidence

This folder contains curated AWS Console, browser and terminal evidence captured during the CloudServe build and final validation.

## Evidence Areas

- account and budget control;
- networking and private subnet placement;
- security-group trust relationships;
- RDS Multi-AZ, backups and failover;
- EC2 Auto Scaling health and automatic replacement;
- ALB target health;
- DNS delegation, ACM issuance and public HTTPS;
- CloudWatch alarms and dashboard;
- controlled failure-test results.

Before public publication, review every image against `SECURITY.md`. Some resource IDs are retained as technical evidence, but credentials, Secret values, RDS endpoints, personal email addresses and full Account IDs must not be exposed.
