# CloudServe Tests

This folder contains the validation and failure tests performed for the CloudServe AWS architecture.

## Test Areas

- Application health endpoint.
- Database connectivity.
- Load balancer target health.
- Auto Scaling instance replacement.
- RDS Multi-AZ failover.
- HTTPS and HTTP redirect.
- CloudWatch and SNS notifications.

The tests demonstrate that the architecture was validated through observed behaviour rather than configuration alone.
